 Make sure you have:
 1. Python
 2. Node.js + npx + npm
 3. expo (For react native )
 4. [Optional] Android command line SDK for emulating in phone (https://developer.android.com/studio#downloads)
 5. [Optional] Download the expo app from google play to your phone.

#  Environment Setup:
Define environment variable "MAPPIFY" which is the base dir of this project
git clone git@github.com:isl-org/ZoeDepth.git lib
conda create -f setup/seg_env.yml
conda create -f setup/zoe_env.yml
conda create -f setup/dj_env.yml 
Set SERVER_IP in frontend/mappifiy-client/utilities/utils.js to your actuall ip address
Install MySQL server from https://dev.mysql.com/downloads/mysql/ or use brew install mysql
Download the .env file from 
    https://1drv.ms/f/c/947b5dc71d5657a7/EpbYOW9zqjlDvg-_gvyQKDQB1w1rnu9njMz1TAdzIEj7hQ?e=zvrs7F 
    and replace <your SQL password> with your actual password. 
    Locate it in backend/mappify-server/MappifyDjango/.env



To run client daemon, run:
cd frontend/mappifiy-client
npm install
npx expo start

To run server daemon, run: 
conda activate dj 
cd /mappify/backend/mappify-server
python manage.py runserver 0.0.0.0:8000
